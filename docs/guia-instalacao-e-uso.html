Instalação

Pronto em menos de 5 minutos

A skill é uma pasta de arquivos — sem build, sem dependências extras além do Node.js para geração de PPTX. Instale uma vez; todo membro do time que atualizar o repositório já tem a versão mais recente.

1

Clone o repositório

O repositório é a fonte única da verdade. Nunca edite cópias locais avulsas.

git clone https://github.com/Dati51632/Dati-design-system.git
Sem acesso? Peça ao responsável pelo design system para te adicionar como colaborador.
2

Posicione a pasta no diretório de skills

O Claude Code carrega skills a partir de .claude/skills/ dentro da pasta do usuário.

C:\Users\<seu-usuário>\.claude\skills\dati-design-system\
3

Instale as dependências para geração de apresentações

Necessário apenas para geração de apresentações. Pré-requisito: Node.js 18+.

cd "C:\Users\<seu-usuário>\.claude\skills\dati-design-system\templates" npm install
4

Verifique a instalação

Peça qualquer material Dati ao Claude. Se ele confirmar os tipos de slide e o registro visual antes de criar, o design system está ativo.

Sinal de sucesso em apresentações: o Claude descreve os tipos de slide e o registro (escuro ou claro) de cada slide antes de gerar o arquivo — esse passo não pode ser pulado.
Como usar

Diga o que precisa.
A skill cuida do restante.

A skill é acionada automaticamente em qualquer pedido de material Dati. Expanda o tipo de material para ver o fluxo e as especificações principais.

Estrutura
Provocação → Diagnóstico → Solução → CTA
Tom
Direto, contraintuitivo, sem jargão de hype
Ênfase
Bold roxo só na palavra-chave — nunca na frase inteira

1
Informe o tema e o objetivo

Qual problema expor? Qual ação o leitor deve tomar ao final?

2
O Claude aplica a estrutura de 4 partes

Provocação, diagnóstico, solução com base sólida, CTA de baixo atrito.

3
Revise o padrão de ênfase no título

Primeira cláusula neutra + segunda cláusula bold roxo. Negrito em palavra, não em frase.

Provas concretas têm prioridade sobre adjetivos. Números, prazos e resultados reais substituem qualquer superlativo.

Eyebrow → H1 navy + ênfase roxo → subtítulo → corpo
Cards
2–4 por linha, ícone + título + descrição
Preço

CTA
Pill roxo, verbo no imperativo, ação verificável
1
Forneça o conteúdo

Título, problema, solução, entregáveis, valor e próximo passo.

2
Defina o tipo de peça

"One-pager de programa" ou "proposta comercial" — cada um tem densidade diferente.

3
Revise o CTA

"Agendar conversa" ou "Falar com especialista" — nunca "Saiba mais" sem destino.

Mínima — sem gradientes decorativos ou formas 3D
1
Forneça o conteúdo e o formato de saída

Markdown, HTML ou texto. O Claude aplica a hierarquia tipográfica automaticamente.

2
Feche com ação concreta

Todo documento termina com um próximo passo verificável.

Se tiver um exemplo real do time, forneça — melhora o resultado.
◆

Regra de ouro

Todo título segue o padrão: cláusula neutra + cláusula de impacto Bold roxo #6838E8. Toda peça termina com um CTA concreto. Toda cor usada vem da paleta oficial — nunca introduza uma cor nova.

Boas práticas

O que funciona,
o que nunca fazer.

Regras que valem para qualquer tipo de material.

✓ Faça sempre
  • ✓Padrão de ênfase no título: cláusula neutra + bold roxo
  • ✓Feche toda peça com CTA concreto e verificável
  • ✓Use apenas cores da paleta oficial
  • ✓Em apresentações: confirme os tipos de slide e o registro visual antes de gerar
  • ✓Texto excedente vai para notas do apresentador, não é cortado
× Nunca faça
  • ×Introduzir cores fora da paleta
  • ×Negrito em frases inteiras — só na palavra de ênfase
  • ×Usar verde em contexto decorativo — só positivo/numérico
  • ×Pular a composição visual em apresentações
  • ×Alterar os 6 slides institucionais fixos
