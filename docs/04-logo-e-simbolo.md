# Logo e símbolo

## Anatomia

O logo é composto por dois elementos que podem aparecer juntos (lockup completo) ou separados:

- **Wordmark**: "dati", minúsculo, Manrope Bold.
- **Símbolo**: uma seta estilizada formada por dois pequenos quadrados de canto arredondado + uma forma de seta bicolor (metade superior ciano `#5BBEED`, metade inferior roxo `#6838E8`). O símbolo substitui o "i" final e funciona como ponto/seta de continuidade — reforça a ideia de "avançar"/"entregar".

Arquivos disponíveis em [`assets/logo/`](../assets/logo/):

| Arquivo | Descrição | Quando usar |
|---|---|---|
| `dati-logo-color.png` | Lockup completo, wordmark navy + símbolo bicolor (ciano/roxo) | Fundo claro/branco — versão padrão |
| `dati-logo-navy.png` | Lockup completo monocromático navy | Fundo claro quando cor não é permitida (ex.: documento P&B) |
| `dati-logo-cyan-mono.png` | Lockup completo monocromático ciano | Uso decorativo pontual sobre fundo escuro |
| `dati-symbol-color.png` | Só o símbolo, bicolor | Favicon, avatar, marca d'água, ícone de app |
| `dati-symbol-purple.png` / `dati-symbol-cyan.png` | Só o símbolo, monocromático | Uso decorativo, ícone monocromático |
| `dati-symbol-crop-*.png` | Símbolo recortado/ampliado ("crop do símbolo") | Elemento gráfico de fundo — ver abaixo |

Para fundo escuro, use a versão branca do wordmark (gere a partir do navy invertendo para branco, ou solicite ao time o arquivo `dati-logo-white.png` que ainda não está neste pacote).

## Regras de uso

- **Espaço de proteção**: mínimo de 1x a altura do símbolo ao redor de todo o lockup — nada de texto, borda ou outro elemento dentro dessa margem.
- **Tamanho mínimo**: 30px (digital) / 0,4cm (impresso) para o lockup completo; 25px / 0,6cm para o símbolo isolado.
- **Fundo**: o logo colorido funciona sobre branco, navy, ou os tons da paleta — nunca sobre fotografia ou fundo com baixo contraste sem um "tapete" sólido atrás.

## O que NÃO fazer (regras explícitas do guia de marca)

- Não usar cores fora da paleta oficial.
- Não aplicar opacidade reduzida.
- Não reposicionar os elementos do símbolo (a proporção entre os dois quadrados e a seta é fixa).
- Não distorcer horizontal ou verticalmente.
- Não rotacionar.
- Não aplicar sombra.
- Não adicionar contorno/stroke.

## Assinatura com tagline

O guia de marca prevê três tons de tagline para acompanhar o logo, a escolher conforme o contexto da peça:

- **Descritiva**: "Tech & Cloud Consulting"
- **Objetiva**: "Tech Strategy & Consulting"
- **Inspiracional**: "Building innovation"
